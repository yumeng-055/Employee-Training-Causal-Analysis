# Analytical notebook

`employee_training_causal_analysis.ipynb` presents the complete English case study: data checks, descriptive statistics, hypothesis testing, regression diagnostics, panel models, model selection, difference-in-differences, parallel trends, and business implications.

Run all cells in order using the project environment. The notebook regenerates the same figures and tables as `python -m src.run_analysis`. Its limitations distinguish descriptive associations from causal conclusions and document the conditions for valid inference.
